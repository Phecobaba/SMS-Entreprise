# Current Oakfield screen pack

This folder records the app as it rendered from the guarded, isolated QA database on 15 November 2026. It is source material for redesign work, not a proposed design.

## Organisation

- `screens/` contains 131 full-page PNGs.
- `screens.md` describes each route/state, role, purpose, reading order and observed issue.
- The archive is published beside this folder as `docs/design/current.zip`.

## Naming

Application screenshots use `<group>-<screen>-<role>-<width>.png`, where width is `1280`, `768` (shell only), or `390`. PDF outputs use `<group>-<screen>-pdf-qa-page-1.png`.

## Safety

All records are synthetic QA fixtures. Credential layouts deliberately replace temporary passwords with `WITHHELD FROM DESIGN PACK`; no password, API key or token is included.
